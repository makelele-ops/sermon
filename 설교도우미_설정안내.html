주일설교묵상 · 2026년 10월 개편

새 디자인과 말씀 도우미 안내

무엇이 바뀌었는지, AI 답변을 켜는 방법, 매주 자동화가 그대로 돌아가는 원리를 정리했습니다.

1. 매주 자동화는 그대로입니다

일요일 밤 코덱스 예약작업이 하던 일은 바꾸지 않았습니다. 같은 순서에 새 기능이 끼어 들어갈 뿐입니다.

1

유튜브 설교 확인 → 새본문.txt 작성 → 묵상 사진 6장 생성

2

sermon-text-to-index.mjs가 index.html의 이번 주 내용 부분만 교체하고 지난주를 보관함으로 옮김 — 새 디자인이 그대로 유지됩니다

3

cloudflare-sync.mjs가 public 폴더로 복사 — 여기서 이제 세 가지를 더 합니다:
· 이번 주 새본문.txt를 content/sermon-notes/날짜.txt로 보관 새로움
· 말씀 도우미 자료 다시 만들기 새로움
· 휴대폰용 가벼운 사진 만들기(장당 2.5MB → 90KB) 새로움

4

점검(verify-sermon-site.mjs) → 깃허브 → 클라우드플레어 자동 배포

확인한 것: 다음 주(10/25) 자동화를 가상으로 끝까지 돌려 봤습니다. 새 주 페이지가 새 디자인으로 만들어지고, 10/18 페이지는 보관함으로 옮겨지며, 코덱스의 점검과 말씀 도우미 점검이 모두 통과했습니다.

2. 디자인에서 바뀐 점

  • 글씨를 사진 위에 올리지 않습니다. 사진은 위, 글은 아래라서 어르신들도 읽기 쉽습니다.
  • 첫 화면: 설교 제목 → 월~토 진행 표시 → 오늘의 묵상 큰 카드 → 6일 목록 → 말씀 도우미 → 지난 설교
  • 묵상 화면: 붙들 말씀 → 묵상 글 → 설교 구간 영상(누를 때만 불러옴) → 질문·적용·기도·가정예배 → 기록
  • 아래쪽 고정 막대(이전 · 묵상 완료 · 다음)가 더 이상 내용을 가리지 않습니다.
  • "지난 설교", "글씨 크게"는 위쪽 막대로 옮겼습니다. 휴대폰이 어두운 화면 설정이면 자동으로 어두운 디자인이 됩니다.
  • 지난 보관함 20편도 모두 새 디자인으로 다시 만들었습니다. 성도님들이 적어 둔 묵상 기록과 완료 표시는 그대로 남습니다.
  • 첫 화면을 열 때 받는 사진 용량이 약 15MB에서 1MB 안팎으로 줄었습니다.

3. 말씀 도우미 AI 켜기 (10분)

지금은 AI 없이도 작동합니다(등록된 설교 원고와 묵상에서 찾아 보여 줌). 아래 두 단계를 하면 질문을 이해하고 직접 답을 써 주는 AI 답변이 켜집니다.

① Claude API 키 만들기

  1. console.anthropic.com에 로그인합니다(구글 계정 가능).
  2. Billing에서 결제 카드를 등록하고 크레딧을 충전합니다. $5(약 7천 원)로 시작하면 충분합니다.
  3. Settings → Limits에서 월 사용 한도를 $10 정도로 걸어 둡니다. 한도를 넘으면 AI가 멈추고 자동으로 자료 검색 답변으로 바뀝니다.
  4. API Keys → Create Key를 누르고 이름을 "sermon"으로 만듭니다. sk-ant-로 시작하는 키를 복사합니다. 이 창을 닫으면 다시 볼 수 없으니 바로 다음 단계로 갑니다.

② 클라우드플레어에 키 넣기

  1. dash.cloudflare.com → Workers & Pages → 이 묵상 사이트 프로젝트를 누릅니다.
  2. Settings → Variables and Secrets → Add
  3. Type: Secret / Variable name: ANTHROPIC_API_KEY / Value: 복사한 키 → Save
  4. Deployments 탭에서 가장 최근 배포의 ⋯ → Retry deployment를 누릅니다. (키는 다음 배포부터 적용됩니다)

키는 클라우드플레어의 Secret에만 넣으세요. 카톡, 이메일, 이 폴더의 파일, 깃허브 어디에도 붙여 넣지 마세요. 혹시 새어 나갔다면 Claude 콘솔에서 그 키를 지우고 새로 만들면 됩니다.

③ 잘 켜졌는지 확인

사이트에서 말씀 도우미를 열고 "이번 주 설교 핵심을 세 줄로 정리해 주세요"를 누릅니다. 답이 한 글자씩 써지고, 위에 "AI 연결 전이라…" 노란 안내가 없으면 성공입니다.

4. 비용과 안전장치

항목내용
질문 1개약 15~25원 (설교 자료 약 1만 자를 함께 읽고 답하기 때문)
한 달 예상질문 300개면 약 6천 원. 사용 한도 $10을 걸어 두면 그 이상 나가지 않습니다.
1명당 제한1분에 6번, 하루 40번
전체 제한하루 400번 — 넘으면 다음 날까지 자료 검색 답변으로 자동 전환
저장되는 것없음. 질문과 대화는 서버에 저장하지 않고, 대화는 그 브라우저 탭을 닫으면 사라집니다.

제한은 기본적으로 서버 기억으로 셉니다. 더 정확하게 세고 싶으면(선택) 클라우드플레어 D1에서 데이터베이스를 만들어 tools/chat-limits.sql을 실행하고, 프로젝트 Settings → Bindings에 D1을 이름 CHAT_LIMITS로 연결하면 됩니다.

OpenAI를 쓰고 싶으면 ANTHROPIC_API_KEY 대신 OPENAI_API_KEY를 넣으면 됩니다. 모델을 바꾸려면 AI_MODEL 변수를 추가합니다(기본: claude-haiku-4-5). 잠시 끄려면 AI_ENABLED=false.

5. 말씀 도우미가 아는 것

  • 2026년 5월 31일부터 모든 주일설교의 실제 설교 자막(21편), 요약 원고(20편), 요일별 묵상 126개 — 목사님이 하신 예화와 표현까지 찾아 답해요
  • "이번 주", "지난주", "지지난주", "10월 11일", "9/20" 같은 날짜 표현 — 지난 보관함 페이지에서는 그 주 설교가 기준입니다.
  • 묵상 화면의 "이 말씀, 내 상황에는 어떻게?"를 누르면 그 요일 묵상을 기준으로 대화합니다.
  • 모든 답에 근거한 설교·요일 번호와 해당 영상 구간 링크가 붙습니다. 목사님이 하지 않은 말은 지어내지 않도록 지시했습니다.

매주 자막도 쌓이게 하기 (꼭 해 주세요): 2026년 5월 31일~10월 18일 21편의 설교 자막은 모두 넣어 두었어요. 앞으로의 설교도 자막이 쌓이도록, 코덱스 예약작업 지시문 끝에 아래 문단을 붙여 넣어 주세요.

설교 자막 보관: 설교 구간(묵상 6일 구간의 시작~끝)의 유튜브 자동 자막 전문을 content/transcripts/설교날짜(예: 2026-10-25).txt 로 UTF-8로 저장한다. 약 90초마다 빈 줄로 문단을 나누고, 각 문단 맨 앞에 영상 시각을 [4:38:01] 또는 [12:30] 처럼 대괄호로 적는다. 요약하거나 고치지 말고 자막 그대로 둔다. 그다음 node tools/cloudflare-sync.mjs 를 실행해 함께 커밋한다. 다른 파일과 디자인(tools/page-template.html, index.html의 weeklyContent 바깥 코드)은 수정하지 않는다.

6. 디자인을 또 바꾸고 싶을 때

디자인의 원본은 tools/page-template.html 하나입니다. 이 파일을 고친 뒤 아래 두 줄을 실행하면 이번 주와 지난 보관함 전체에 한 번에 적용됩니다.

node tools/apply-page-template.mjs node tools/cloudflare-sync.mjs

index.html을 직접 고쳐도 다음 주 자동화에서 유지되지만, 지난 보관함에는 적용되지 않습니다. 그래서 템플릿을 고치는 쪽을 권합니다.

7. 내 컴퓨터에서 미리 보기

설교도우미_미리보기.bat을 더블클릭하면 브라우저에 http://127.0.0.1:8765가 열립니다. 말씀 도우미는 AI 없이 자료 검색으로 답합니다. 내 컴퓨터에서 AI까지 시험하려면 이 폴더에 .dev.vars 파일을 만들고 ANTHROPIC_API_KEY=키 한 줄을 적으세요(깃허브에는 올라가지 않게 막아 두었습니다).

8. 점검 명령

node tools/verify-sermon-site.mjs (코덱스가 쓰던 사이트 점검) node tools/verify-sermon-assistant.mjs (말씀 도우미 점검 · 실제 AI 요청은 보내지 않음)
